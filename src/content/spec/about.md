# 关于 Shirone

欢迎来到 **Shirone**（白音）的演示站点——一个基于 **Material 3 Expressive（M3E）** 设计体系的、富有表现力的动漫风博客主题。

::github{repo="LyraVoid/Shirone"}

## ✦ 设计与理念

Shirone 想把动漫美学的温度与现代 Web 工程的严谨揉在一起：

- **动态色彩法术**：完整的动态 HCT 配色生成，无缝响应明暗模式与用户偏好，且不产生任何布局抖动。
- **无缝外壳导航**：由 Swup 驱动的常驻应用外壳，带来连播不断的音乐、顺滑的页面切换与状态保留。
- **丰富故事魔典**：Markdown 与 MDX 写作，支持 KaTeX 数学公式、Mermaid 图表、可交互提示块、富有表现力的代码块，以及自适应图片画廊。
- **零额外负担**：可选集成（评论、统计、音乐组件）按需动态加载——关闭时零 DOM 占用、零打包体积。

## ✦ 技术栈

- **框架**：[Astro 7](https://astro.build/) 与 [Svelte 5](https://svelte.dev/)（Runes 驱动的岛屿）
- **样式**：[Tailwind CSS 4](https://tailwindcss.com/) 与 [Stylus](https://stylus-lang.com/)
- **设计标准**：[Material 3 Expressive](https://m3.material.io/)
- **字体排印**：Outfit 与 Yozai（悠哉圆体），构建时自动子集化
- **搜索引擎**：[Pagefind](https://pagefind.app/) 离线全文搜索
