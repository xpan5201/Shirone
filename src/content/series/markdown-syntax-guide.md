带你走一遍 Shirone 的 Markdown 能力，从最基础的语法
一路到主题特有的扩展。

- **第一部分**从每篇文章都支持的 Markdown 原生语法开始。
- **第二部分**讲建立在它之上的扩展功能。
- **第三部分**深入 Shirone 自己的增强（提示块、内容
  注解，以及其他的 M3E 容器）。

这个系列已经**完结**。注意 `defaultCategory` 只是兜底：
文章仍然可以自己声明 `category` 来覆盖它。
